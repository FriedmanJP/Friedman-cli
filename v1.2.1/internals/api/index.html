API Reference

Agents invoke the frdc executable from the shell rather than importing the Julia package directly; see Automated Pipelines & JSON Envelopes and Agent Guide for the supported CLI contract. The exported Julia functions below exist for embedding the CLI dispatcher inside external scripts, custom harnesses, REPL wrappers, and the JSON-RPC MCP loop.

Exported Entry Points

Friedman.main — Function
main(args=ARGS)

Entry point: dispatch and exit non-zero on failure.

source
Friedman.build_app — Function
build_app() -> Entry

Construct the full CLI command tree.

source
Friedman.run_cli — Function
run_cli(args)::Cint

Single entry shared by main (dev) and julia_main (compiled). Exit codes (P1-4): 0 ok · 2 usage · 3 data · 4 config · 5 model · 6 env · 1 internal.

source
