API Reference

Agents use the friedman command line, not this page. The Julia API below exists for embedding the CLI engine (REPL, scripts, the MCP server) and for developers hacking on the command tree. End-user behavior — options, output tables, envelope schema — is documented under the CLI Reference and generated per command; nothing here replaces it.
