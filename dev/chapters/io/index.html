Input-Output & Production Networks

Classical linear input–output accounting, MRIO database ingestion (oecd, wiod, exiobase3, eora26, gloria), Leontief/Ghosh multipliers, hypothetical extraction, structural decomposition analysis, and Baqaee–Farhi (2019, 2020) nonlinear general-equilibrium production network analysis live under frdc io across the linear io and nonlinear io bf families. See MacroEconometricModels.jl — Input-Output & Networks for mathematical derivations.

Quick Start

Omit --data on any io or io bf command to run directly on the built-in Miller–Blair 2-sector benchmark (Agriculture, Manufacturing), inspect the Leontief inverse $L = (I - A)^{-1}$, and solve a Baqaee–Farhi productivity shock:

<!– capture –>

frdc io leontief --matrix L
             Leontief Inverse (L)
┌───────────────┬─────────────┬───────────────┐
│    sector     │ Agriculture │ Manufacturing │
├───────────────┼─────────────┼───────────────┤
│  Agriculture  │   1.25412   │   0.330033    │
│ Manufacturing │  0.264026   │    1.12211    │
└───────────────┴─────────────┴───────────────┘

The command returns leontief_inverse_l (an extra dollar of agricultural demand induces 1.25412 of total agricultural output and 0.264026 of manufacturing output, or both technical_coefficients_a and leontief_inverse_l under --matrix both; pass --data <path> alongside --n-sectors and --n-fd for custom CSV/ICIO tables).

Every analysis leaf runs offline against the bundled :wiot fixture when --data is omitted. For multi-step custom workflows, parse raw CSV or OECD ICIO files once with io load (or repair/collapse them via io balance and io aggregate) using --save-model <stem.jld2>, then pass the persisted IOData handle to --data across downstream multiplier, linkage, footprint, and Baqaee–Farhi commands.

Classical Leontief, Ghosh, Extraction & MRIO Accounting (io)

In a $S$-sector open input–output table with intermediate technical matrix $A_{ij} = Z_{ij} / x_j$ and output-allocation matrix $B_{ij} = Z_{ij} / x_i$, gross output $x$ responds to final demand $y$ via the Leontief inverse $L$, while supply-side value-added $v'$ pushes gross output via the Ghosh inverse $G$:

\[L = (I - A)^{-1}, \quad \Delta x = L \, \Delta y; \qquad G = (I - B)^{-1}, \quad \Delta x' = \Delta v' \, G.\]

Baqaee–Farhi Nonlinear Production Networks (io bf)

When elasticities of substitution across intermediates ($\theta$), final demand ($\sigma$), nests ($\epsilon$), or primary factors ($\eta$) deviate from Cobb–Douglas (1.0), Hulten's linear approximation $\Delta \ln Y \approx \lambda' \Delta \ln A$ breaks down for large shocks or distorted wedges ($\mu_i \neq 1$). io bf builds a calibrated nonlinear CES/nested network (network), saves it via --save-model <path.fmod>, and solves exact nonlinear counterfactual equilibria:

\[\frac{d \ln Y}{d \ln A_i} = \lambda_i^{\text{cost}}, \qquad \Delta \ln Y \approx \lambda' \Delta \ln A + \frac{1}{2} \Delta \ln A' \, \Xi \, \Delta \ln A.\]

  • io bf network: Builds network Domar shares (lambda, lambda_rev, wedges mu; supports --nests single|two, --factors single|va-cats, vector overrides --theta, --mu).
  • io bf equilibrium: Solves exact nonlinear counterfactual output dlogY, sector quantities dlog_x, and prices dlog_p for TFP (--dlog-a), labor (--dlog-l), or markup (--dlog-mu) shocks via Newton or fixed-point iteration.
  • io bf elasticities, local, wedges, misallocation, shock-curve: Computes full general-equilibrium price incidence matrices, second-order Hulten Hessians $\Xi$, distortion-wedge decompositions ($\lambda^{\text{cost}}$ vs. $\lambda^{\text{rev}}$), efficiency misallocation gaps (--point efficient|observed), and multi-point shock curves comparing exact nonlinear vs. Hulten linear vs. second-order approximations.

<!– capture –>

frdc --quiet io bf network --theta 0.5,1.2 --save-model bf_net.fmod
frdc io bf equilibrium --model bf_net.fmod --dlog-a 0.05,0.0 --method newton

Common Pitfalls

  1. Forgetting --n-sectors when loading custom CSV IO tables: The built-in 2-sector example runs with zero flags, but custom CSV files passed via --data must declare --n-sectors (and --n-fd, defaulting to 1).
  2. Expecting Type II (--type II) multipliers or --kind employment without household/employment rows: When a CSV matrix omits compensation or employment accounts, employment/Type-II requests fail validation cleanly (data/* error).
  3. Treating maxiter-truncated io bf equilibrium as a CLI error: Non-convergence inside io bf equilibrium reports converged = false in bf_equilibrium_summary (exit 0, result payload) rather than aborting with exit 5; always check the converged row or reduce --damping.
  4. Network access and credentials in io download: io download is the only network-touching command in the io family (io sources runs offline); pass --offline in restricted environments to fail cleanly with exit 6 (env/network), and supply --email and --password when fetching eora26.
  5. Re-calibrating io bf networks on every counterfactual: Persist a calibrated ProductionNetwork once via io bf network --save-model (.jld2 native or .fmod) and pass --model to equilibrium, elasticities, local, wedges, misallocation, and shock-curve so all counterfactuals share identical elasticities and markups.
