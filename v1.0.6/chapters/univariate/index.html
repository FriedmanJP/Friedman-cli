Univariate, Filters & Spectral

Single-series macroeconomic analysis in Friedman-cli spans trend-cycle decomposition (friedman filter), nonparametric and filter frequency-domain diagnostics (friedman spectral), Box–Jenkins, fractional, mixed-frequency, and distributed-lag estimators (estimate univariate), general Gaussian state-space filtering (estimate regression statespace), and time-varying parameter regressions (estimate regime tvp). See MacroEconometricModels.jl — Univariate & Filters for mathematical details.

Quick Start

Decompose U.S. real GNP (:gnp_hamilton) with the Hamilton regression filter, inspect spectral power, and fit an automatic BIC ARIMA model with 4-step forecasts:

Economic Time-Series Filters

A trend-cycle decomposition separates an observable series $y_t$ into a stochastic or smooth trend $\tau_t$ and a stationary cyclical component $c_t = y_t - \tau_t$. The Hodrick–Prescott (HP) filter solves

\[\min_{\{\tau_t\}} \sum_{t=1}^T (y_t - \tau_t)^2 + \lambda \sum_{t=2}^{T-1} \left[(\tau_{t+1}-\tau_t) - (\tau_t-\tau_{t-1})\right]^2,\]

while Hamilton (2018) avoids spurious end-of-sample cycles by projecting $y_{t+h}$ onto $(1, y_t, \dots, y_{t-p+1})$, boosted HP (bhp) iterates HP to whiten cycles until ADF or BIC convergence, Beveridge–Nelson (bn) extracts long-horizon conditional expectations, Baxter–King (bk) isolates business-cycle frequencies, and X-13ARIMA-SEATS (x13) extracts seasonal factors.

filter hp--lambda (1600.0 quarterly)hp_filter
filter bhp--stopping BIC|ADF|fixed, --max-iterboosted_hp_filter
filter hamilton--horizon 8, --lags 4hamilton_filter

Spectral & Cross-Spectral Analysis

For covariance-stationary $y_t$ with autocovariances $\gamma(k)$, the power spectral density concentrates variance across angular frequencies $\omega \in [0, \pi]$:

\[f_{yy}(\omega) = \frac{1}{2\pi} \sum_{k=-\infty}^{\infty} \gamma(k) e^{-i \omega k}.\]

Compute time-domain ACF/PACF and bivariate cross-correlations via spectral acf (acf_pacf, cross_correlation), unsmoothed FFT ordinates via spectral periodogram (periodogram), Welch/lag-window/AR smoothed spectra via spectral density (spectral_density), and coherency, gain, and phase between two series via spectral cross (cross_spectral_analysis).

ARIMA, SARIMA, ARFIMA, ARDL, NARDL & MIDAS

Univariate dynamic models span short-memory differenced processes, seasonal multiplicative forms, fractional integration $(1-L)^d$, mixed-frequency regressors, and bounds-tested cointegrating lag structures:

\[\phi(L)(1-L)^d (y_t - \mu) = \theta(L)\varepsilon_t, \qquad \varepsilon_t \sim (0, \sigma^2).\]

  • Short & Seasonal Memory: estimate univariate arima (pass --d 0 --q 0 for pure AR, --p 0 --d 0 for MA, or omit --p for automatic criterion search) and estimate univariate sarima (--auto selects $(p,d,q)(P,D,Q)_s$). Both pair with forecast, predict, and residuals.
  • Fractional Integration: estimate univariate arfima jointly estimates $d \in (-0.5, 0.5)$ alongside ARMA dynamics via CSS or exact MLE.
  • Mixed-Frequency Regressions: estimate univariate midas projects low-frequency targets on high-frequency lags using Almon, Beta (beta2/beta3), Exponential Almon, or U-MIDAS polynomial weights (midas_weight_curve, midas_coefficients, midas_diagnostics).
  • Cointegrating ARDL & Asymmetric NARDL: estimate univariate ardl estimates optimal $(p, q_1, \dots, q_k)$ lag lengths alongside levels-relationship long-run multipliers (ardl_long_run_coefficients), testable via test coint ardl-bounds. estimate univariate nardl decomposes explanatory series into partial sum positive and negative cumulative shocks $x_t^+, x_t^-$, computing bootstrap cumulative dynamic multipliers (nardl_cumulative_dynamic_multipliers) testable via test nardl-symmetry.

State-Space & Time-Varying Parameters

Linear Gaussian state-space systems filter and smooth latent states $\alpha_t$ given observation equations $y_t = Z \alpha_t + d + \varepsilon_t$ and transition equations $\alpha_{t+1} = T \alpha_t + c + R \eta_t$.

  • Local Level & General [statespace]: Pass estimate regression statespace with a TOML [statespace] config (GMM, SMM, Systems, State-Space & Policy), or inspect local-level / local-linear-trend filtered and smoothed state paths directly with predict regression statespace (--kind local-level|local-linear-trend) and standardized innovations with residuals regression statespace.
  • Time-Varying Parameter Regression: estimate regime tvp treats regression slopes $\beta_t = \beta_{t-1} + \eta_t$ as random walks estimated via exact Kalman filtering and Rauch–Tung–Striebel smoothing (tvp_hyper_parameters, tvp_coefficient_paths, tvp_diagnostics).

Common Pitfalls

  1. Omitting --dep on ardl and nardl: Unlike univariate arima (--column 1), estimate univariate ardl and estimate univariate nardl require an explicit dependent column name or index via --dep.
  2. Expecting separate ar / ma subcommands: Pure AR($p$) and MA($q$) models use estimate univariate arima with --d 0 and --q 0 (or --p 0) rather than separate leaves.
  3. Interpreting HP endpoints mechanically: Standard filter hp exhibits severe end-of-sample bias; compare against filter hamilton or filter bhp and verify transfer attenuation via spectral transfer.
  4. Missing --hf-data in midas: Supplying a single dataset without --hf-data triggers a usage error unless both low-frequency (<data>) and high-frequency (--hf-data) inputs plus --m frequency ratio are passed.
