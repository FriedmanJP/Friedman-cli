Common Options & Globals

Every leaf that produces tabular output supports --format/-f (table|csv|json) and --output/-o (<path> to write to a file instead of stdout). Leaves accepting structured specifications add --config <path> (see Model Cards & Config Grammar); plot-capable leaves add --plot and --plot-save <path>.

Leading agent globals go before the command: --seed N, --quiet/-q, --json, and --no-color. See Pipelines, Handles & Reproducibility and the Agent Guide for the complete JSON envelope and typed handle contract.

Help & Machine Schema

Every node and leaf accepts --help (-h). Machine-readable draft-07 input schemas and declared table keys come from friedman schema:
