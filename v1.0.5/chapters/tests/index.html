Hypothesis Testing & Diagnostics

Diagnostic and specification tests in Friedman-cli live under friedman test across 11 families (unit-root, coint, vecm, multivariate, serial, stability, panel, pvar, iv, did, plus standalone model diagnostics). Use the decision guide below to select the right test before or after estimating any model. See MacroEconometricModels.jl — Hypothesis Tests for asymptotic distributions and finite-sample adjustments.

Quick Start

Run the Augmented Dickey–Fuller unit-root test (adf), KPSS stationarity test (kpss), and Johansen trace/max-eigenvalue cointegration rank test on :denmark:

<!– capture –>

friedman test unit-root adf :denmark --column 1 --trend constant
       ADF Test: LRM
┌────────────────┬────────┐
│     metric     │ value  │
├────────────────┼────────┤
│ Test statistic │ -1.263 │
│      Lags      │   2    │
│    p-value     │ 0.6172 │
└────────────────┴────────┘

The command returns adf_test (Test statistic = -1.263, Lags = 2, p-value = 0.6172—failing to reject the unit-root null for LRM); complement unit-root rejection failures with test unit-root kpss (whose null is stationarity) and multi-series rank checks via test coint johansen.

Stationarity, Structural Breaks & Explosive Episodes

Classical unit-root tests lose power against trend-stationary alternatives with structural breaks or smooth transitions, while asset-price bubbles leave mildly explosive right-tailed signatures:

\[\Delta y_t = \alpha + \beta t + \gamma y_{t-1} + \sum_{j=1}^p \delta_j \Delta y_{t-j} + \sum_{k=1}^K \left(a_k \sin\tfrac{2\pi k t}{T} + b_k \cos\tfrac{2\pi k t}{T}\right) + \varepsilon_t.\]

  • Confirmatory & Break-Aware Unit Roots: Combine adf/dfgls/pp/np/ers against kpss; switch to Zivot–Andrews (za), Lee–Strazicich (lm-unitroot), or two-break ADF (adf-2break) for endogenous breaks, fourier-adf/fourier-kpss for smooth breaks, and hegy for quarterly/monthly seasonal roots.
  • Structural Stability & Bubbles: Locate single breaks via test stability andrews or multiple breaks via Bai–Perron bai-perron, monitor recursive residuals via cusum/cusumsq/nyblom, and date speculative bubbles via Phillips–Shi–Yu right-tailed sadf / gsadf.

<!– capture –>

friedman test stability bai-perron :nile --response 1 --max-breaks 3 --criterion bic
      Bai-Perron Test

│      metric      │ value │
├──────────────────┼───────┤

Cointegration, VAR Diagnostics & Causal Specification Tests

  • Johansen, ARDL Bounds & VECM Restrictions: Determine cointegration rank with test coint johansen (--lags, --trend constant), verify mixed-$I(0)/I(1)$ long-run relations via Pesaran–Shin–Smith test coint ardl-bounds, test regime-switching cointegration with test coint gregory-hansen, and impose exact linear restrictions $H\varphi$ / $A\psi$ on estimated VECMs via test vecm beta|alpha|joint|known-beta|weak-exog (Priors, SVAR & VECM Identification).
  • VAR Order, Granger Causality & Residuals: Select lag orders with test multivariate lagselect, test modulus $< 1$ with test multivariate stability, test block/pairwise exclusion with test multivariate granger, and check residual non-normality/heteroskedasticity/non-Gaussian identifiability via test normality, test serial heteroskedasticity, and test identifiability.

Common Pitfalls

  1. Running test unit-root kpss and reading $H_0$ backwards: Unlike adf, pp, and dfgls (null: unit root), kpss and fourier-kpss test the null hypothesis of stationarity; low $p$-values under KPSS reject stationarity.
  2. Omitting --dep on regression diagnostics (vif, white, chow, cusum, park-added): Column-index time-series tests take --column 1 (or --response), whereas regression diagnostics require explicit dependent variable selection via --dep.
  3. Leaving default high mc-reps 999 on sadf/gsadf or reps 1000 on hansen-linearity in interactive loops: Set leading --seed and moderate bootstrap/Monte Carlo counts when iterating rapidly, then run full 999+ replications for final publication tables.
